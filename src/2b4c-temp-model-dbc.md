# Modèles temporelles
---
**Borne \\(\Delta\\) sur le temps de transmission**: si un processus \\(p\\) envoie un message vers \\(q\\) à un instant \\(t\\), alors \\(q\\) reçoit le message avant \\(t+\Delta\\).

**Borne \\(\Phi\\) sur la vitesse relative des processus**: si le processus le plus rapide prend \\(x\\) unités de temps pour un traitement, alors le processus le plus lent ne peut pas prendre plus \\(x\Phi\\) unités de temps pour faire le même traitement.
