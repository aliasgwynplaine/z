# notre (sorbonne) modèle
---
Voici le modèle qu'on utilise pour la plus partie des algorithmes. Si aucun modèle n'est spécifie, alors on parle de ce modèle là.

+ Ensemble de processus séquentiels indépendants. susceptibles de subir des pannes franches. suite d'une panne franche, le processus s'arrête deffinitivement.
+ Communication par échange de messages. point-à-point. Canaux fiables (*eventually arrives*)
+ Système asynchrone ( sauf qu'on dit le contraire ) [2b4e-temp-model-dnb](2b4e-temp-model-dnb.md)
+ Pas d'horloge commune [2b4b-clocks](2b4b-clocks.md)

un processus qui ne tombe pas en panne sur toute une exécution donnée est dit **correct**, sinon il est dit **fautif**.
